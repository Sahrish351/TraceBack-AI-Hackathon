## 1. Executive Statement of Integration Integrity

TraceBack AI complies strictly with ethical submission standards:
1. **No Fake Connections:** We never display a green "Connected" badge or claim an external network handshake when only local logic ran.
2. **Deterministic Security:** All financial calculations (quantity variances, contract price variances, tax differences) are calculated deterministically by pure TypeScript code, never guessed or generated by an LLM.
3. **Transparent Fallbacks:** When external sponsor APIs are unconfigured or unreachable, the system executes high-fidelity local implementations and marks them honestly as `Local / demo mode` in both backend responses and the user interface.

## 2. Detailed Technical Audit by Sponsor

### 2.1 Zetaris (Enterprise Data Virtualization)

- **Official Role in Architecture:** Virtualizing multi-source joins across enterprise purchase orders (ERP), warehouse delivery notes (WMS), supplier invoices (AP), and master contract catalogs.
- **Configured Endpoint:** `process.env.ZETARIS_API_URL` (Defaults to empty; `.env.example` lists placeholder `https://api.zetaris.example.com/v1`).
- **Authentication & Request Schema:**
  - Header: `Authorization: Bearer <ZETARIS_API_KEY>`
  - Request: `POST /query` with body `{ query: string, database?: string }`
  - Expected Response: `{ rows: Record<string, any>[], metadata: { rowCount: number, executionTimeMs: number } }`
- **Actual Runtime Reality:**
  - Because no enterprise Zetaris tenant credentials have been provisioned to the participant, `ZetarisClient.ts` executes on its local in-memory SQLite virtualization federator.
  - The SQLite federator executes the canonical 4-way join across the local normalized CSV datasets.
- **Honest Status Displayed:** `Local / demo mode` (Engine: `in-memory-sqlite-virtualizer`).
- **Exact Blocker:** No active Zetaris enterprise tenant URL or API key is provisioned.
- **Participant Action Required:** If organizers provide a live Zetaris sandbox tenant, set `ZETARIS_API_URL` and `ZETARIS_API_KEY` in the local `.env` file.

### 2.2 Meterless (Autonomous Agent Orchestration & H-MEM)

- **Official Role in Architecture:** Coordinating the 5-step investigative mission (`scoutIntent` → `fetchUnifiedData` → `detectDiscrepancies` → `scoreConfidence` → `draftExplanation`) and maintaining persistent state across human audit decisions.
- **Configured Endpoint:** `process.env.METERLESS_API_URL` (Defaults to empty; `.env.example` lists placeholder `https://agent.meterless.example.com/v1`).
- **Authentication & Request Schema:**
  - Header: `Authorization: Bearer <METERLESS_API_KEY>`
  - Request: `POST /missions/run` with `{ objective: string, poId: string, context: Record<string, any> }`
- **Actual Runtime Reality:**
  - `MeterlessMission.ts` runs the full 5-step sequential agent relay locally.
  - Step transitions, timestamps, thoughts, actions, and observations are logged into an observable mission trace.
  - Reviewer decisions are stored in the in-memory H-MEM map (`hMem.set(key, value)`).
- **Honest Status Displayed:** `Local / demo mode` (Architecture: `5-step autonomous relay + H-MEM`).
- **Exact Blocker:** Hosted Meterless remote webhook orchestrator endpoint is not configured.
- **Participant Action Required:** If utilizing a hosted Meterless runner, set `METERLESS_API_URL` and `METERLESS_API_KEY` in `.env`.

### 2.3 NVIDIA NIM (Model Inference & Natural Language Explainer)

- **Official Role in Architecture:** Synthesizing an evidence-grounded audit summary and drafting a professional supplier clarification letter.
- **Configured Endpoint:** `https://integrate.api.nvidia.com/v1/chat/completions` (Documented, real NVIDIA NIM API endpoint).
- **Model Identified:** `meta/llama-3.1-8b-instruct`.
- **Authentication & Request Schema:**
  - Header: `Authorization: Bearer <NVIDIA_API_KEY>` (Expected format: `nvapi-...`)
  - Request: Standard OpenAI-compatible Chat Completions payload with structured system/user messages.
- **Actual Runtime Reality:**
  - When `NVIDIA_API_KEY` is present, `NvidiaExplainer.ts` sends a live HTTPS request with an 8-second timeout guard.
  - When `NVIDIA_API_KEY` is absent, the client safely falls back to its deterministic explanation template.
  - **Arithmetic Guardrail:** In both live and fallback modes, the model is strictly forbidden from computing numbers. All discrepancy amounts (e.g. Rs 10,000 for PO-1042) are calculated in pure TypeScript and injected as immutable facts.
- **Honest Status Displayed:** `Local / demo mode (Deterministic Fallback)` (Engine: `deterministic-rule-template`).
- **Exact Blocker:** No personal NVIDIA developer API key (`nvapi-...`) has been added to `.env`.
- **Participant Action Required:** Obtain a free API key at [build.nvidia.com](https://build.nvidia.com/) and paste `NVIDIA_API_KEY=nvapi-...` into `.env`.
